# Simple Task API

REST API do zarządzania zadaniami, stworzone w Node.js z wykorzystaniem frameworka Express oraz bazy danych MongoDB.

---

## 🚀 Główne funkcje

- **Pełne wsparcie CRUD**: Tworzenie, odczytywanie, aktualizowanie i usuwanie zadań.
- **Zaawansowane filtrowanie**: Filtrowanie listy zadań według statusu oraz priorytetów.
- **Autoryzacja użytkowników**: Prosty system uwierzytelniania oparty na tokenach.
